# Sign Up Form

Formulário de cadastro completo desenvolvido como parte da trilha Intermediate HTML and CSS do [The Odin Project](https://www.theodinproject.com/lessons/node-path-intermediate-html-and-css-sign-up-form), com foco em **formulários HTML**, **validação** e **design com CSS**.

## Objetivo do Projeto

O objetivo principal era praticar:
- Criação e estilização de formulários HTML
- Validação de campos com atributos HTML5
- Design visual profissional
- Tipografia customizada com @font-face
- Estados de foco e interação em inputs
- Composição de layouts divididos

## O que é?

Um formulário de cadastro (sign-up) moderno contendo:
- Layout em duas colunas com imagem de destaque
- Campos de entrada validados (nome, sobrenome, email, telefone, senha)
- Validação de senha com requisitos específicos
- Confirmação de senha
- Estados visuais em inputs (focus, valid, invalid)

## Como usar

1. Abra o arquivo `index.html` em seu navegador
2. Preencha os campos do formulário
3. A senha deve ter entre 8-16 caracteres, incluindo letras e números
4. Confirme a senha no campo correspondente
5. Clique em "Create Account" para submeter o formulário

## Funcionalidades

- **Validação de Campos**: Validação HTML5 nativa para email, telefone e senha
- **Requisitos de Senha**: Mínimo de 8 caracteres com letras e números
- **Estados Visuais**: Feedback visual em inputs (focus, válido, inválido)
- **Layout Dividido**: Seção de imagem e seção de formulário
- **Tipografia Customizada**: Fonte custom para o logo
- **Design Profissional**: Interface limpa e moderna
- **Campos Organizados**: Formulário estruturado com labels claros

> **Nota**: Este projeto foca em validação HTML5 nativa e estilização CSS. Não há intenção de explorar validação de formulário com JavaScript neste estágio.

## Tecnologias Utilizadas

- HTML5 (formulários e validação)
- CSS3 (Flexbox, @font-face, pseudo-classes)
