# Sign Up Form

Complete sign-up form developed as part of the Intermediate HTML and CSS path of [The Odin Project](https://www.theodinproject.com/paths/full-stack-javascript/courses/intermediate-html-and-css), with a focus on **HTML forms**, **validation**, and **CSS design**.

## Project Objective

The main objective was to practice:
- Creating and styling HTML forms
- Validating fields with HTML5 attributes
- Professional visual design
- Custom typography with `@font-face`
- Focus and interaction states for inputs
- Building split layouts

## What is it?

A modern sign-up form containing:
- Two-column layout with a featured image
- Validated input fields (first name, last name, email, phone, password)
- Password validation with specific requirements
- Password confirmation
- Visual input states (focus, valid, invalid)

## How to use

1. Open the `index.html` file in your browser
2. Fill out the form fields
3. The password must be between 8 and 16 characters, including letters and numbers
4. Confirm the password in the corresponding field
5. Click "Create Account" to submit the form

## Features

- **Field Validation**: Native HTML5 validation for email, phone, and password
- **Password Requirements**: Minimum of 8 characters with letters and numbers
- **Visual States**: Visual feedback on inputs (focus, valid, invalid)
- **Split Layout**: Image section and form section
- **Custom Typography**: Custom font for the logo
- **Professional Design**: Clean and modern interface
- **Organized Fields**: Form structured with clear labels

> **Note**: This project focuses on native HTML5 validation and CSS styling. There is no intention to explore JavaScript form validation at this stage.

## Technologies Used

- HTML5 (forms and validation)
- CSS3 (Flexbox, `@font-face`, pseudo-classes)
